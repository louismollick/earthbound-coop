### M6 review fixes (m6fix)
- Every datagram's header now carries the client's connection nonce (epoch), both ways (protocol v2), and each side ignores other epochs. A HELLO is validated first and never replaces an open connection: a new process at the same endpoint gets REJECT busy until the old one says BYE (with its own nonce) or goes silent for 10 s. The client's connect timeout is now 15 s.
- HELLO carries a compatibility fingerprint: viewport, simulation build options (audio, verify, battle letterbox, B-opens-menu), game revision (git commit plus `+dirty.<hash>` of local changes under `src/`, `port/unix/`, `cmake/`, from `port/unix/net/build_id.cmake` on every build), a hash of every embedded asset, and the savestate layout. The Host's REJECT names each difference.
- `netrun.py` `main()` requires clean completion of every requested machine plus `frames/60 - 5` shared hash points. `--net-wait-players` now holds whenever fewer Players are in, after a leave too: without that, the rejoin depended on a HELLO beating the Host's uncapped solo run (2800 frames in 0.2 s).
- Scenarios, each failing on the pre-fix build: `net_spoof_hello` (garbage HELLO and a copied HELLO with a new nonce from P2's endpoint: `DROP P2 restarted`), `net_rejoin` (a restart through the same proxy link, then a replay of the old connection's packets plus a BYE built from its header: `DROP P2 restarted`, `DROP P3 quit`), `net_build_mismatch` (wide Host, native client: desync at frame 60), `net_harness` (`true`/`false` as the game: exit 0). The proxy can now record a link and inject datagrams from either end.
