# k8x12

The kanji font of the Japanese (kanji) Language (`ebtools/ja_kanji.py`): k8x12 by Num Kadoma, an 8x12 Japanese bitmap font whose kanji are 7x11, so they keep Mother 2's 8 px letter grid.

- `k8x12.bdf`: unmodified, from `k8x12_bdf_2021-05-05.zip` (SHA-256 `305ab94915ec3c8e1ada08f493ee5bfdd21e2710a97d7c4d4272444d8e18ff40`), <https://littlelimit.net/k8x12.htm>. pack-all rasterizes its 8 px wide glyphs for the characters the kanji script uses.
- `k8x12.txt`: the font's manual from the same archive, with its license.
